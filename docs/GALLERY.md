# Screen gallery

[Back to README](../README.md)

Web images use the real embedded HTML with fictional local fixtures. OLED images are the actual production C++ renderer at 128x64, enlarged 4x. They are screen examples, not photographs or proof of physical peripheral tests. No private bot token, router password or device backup is included.

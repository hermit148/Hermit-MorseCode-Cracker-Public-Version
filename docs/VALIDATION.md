## Published firmware

The upload package contains two versions, both with five direct GPIO buttons:

| Version | Microphone | Compiled application | Translation units |
|---|---|---:|---:|
| Non-mic | Disabled | 1,609,584 / 3,145,728 bytes | 45 |
| Mic | INMP441 SCK2 / WS21 / SD20 | 1,651,808 / 3,145,728 bytes | 46 |

The mic build links the actual ESP_I2S implementation and requires a physical
10k pullup from GPIO2 to 3V3. Native USB18/19 is preserved. Pin guards reject
collisions, reserved USB pins and mic builds that disable native USB.

Compile-time keyboard, debounce/hold/repeat/rollover, Wi-Fi, timing and OLED
checks passed. Browser checks cover all five pages at 320/390/768/1280 px,
authentication, shared keyboard drafts, settings, Wi-Fi and both direct-button
microphone notices. The documentation exporter checks the mic wiring notice,
mobile overflow and JavaScript errors using local fictional data.

are retained as bench evidence and do not certify the optional microphone:

| Runtime Morse core | 346,332 assertions |

| BLE/HTTP soak | 86 polls, 0 errors over one minute |
| Maximum history with BLE initialized | 25,455 bytes; all 24 maximum-length records |
| Production boot POST | OLED found; GPIO input setup, flash, settings, RAM and AP passed |

The stress suite adds a loopback client/task alongside BLE. Transient low-RAM
readiness warnings occurred; final HTTP/history checks passed. Concurrent BLE
plus TLS delivery still needs a separate acceptance test. No actual external
Telegram/Discord delivery or optional mic performance was certified.

## Diagrams and package checks

Both hardware diagrams have checked netlists and their own matching firmware
filename. Checks cover OLED power/I2C, all five independent switch contacts,
common ground, piezo polarity/series resistor, USB separation and no GPIO shorts.
The mic diagram also covers its power, left-channel selection, GPIO2 pullup,
SD pulldown and bypass capacitor. The physical mapping is logical GPIO labeling,
not a claim about a particular SuperMini board's header positions.

The non-mic Wokwi diagram is checked against official part endpoints. Its
standalone wiring-test sketch is supplied. Live Wokwi editor execution was
unavailable, so no published project or full microphone simulation is claimed.

Each complete image is 4 MB: bootloader 0x0, partitions 0x8000, boot metadata
0xE000, application 0x10000. Packaged hashes and source hashes match; the NVS
region is blank. Only the two named complete images are included. All local
document/image links and heading anchors are checked during packaging.

Portable metadata: [non-mic](../firmware/build-info.json),
[mic](../firmware/mic-direct/build-info.json),
[binary hashes](../firmware/SHA256SUMS.json).

## Hardware checks still required

The optional microphone has not been physically accepted for tone decoding,
noise behavior or repeated cold starts with the GPIO2 pullup. The connected
board was not reflashed or erased during packaging. Verify actual OLED pixels,
switch contacts, sound and router/provider operation on the finished assembly.

Web screenshots use fictional fixtures. The 48 OLED examples are generated by
the actual C++ renderer at 128x64 and enlarged 4x, rather than panel photographs.
Private device dumps, NVS, runtime credentials and serial logs are excluded.
